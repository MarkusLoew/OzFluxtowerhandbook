# Contributing to the OzFlux Tower Handbook

Thank you for your interest in helping improve this handbook for building and maintaining Australian flux towers.

We welcome input from researchers, technicians, site managers, and anyone with practical experience in flux tower design, installation, operation, and safety.

## How to contribute
Any contributions are welcome:

- Improve existing guidance for tower construction, sensors, power, communications, calibration, rigging, and field workflows.
- Add practical notes, lessons learned, troubleshooting steps, and examples from building and operating flux towers under Australian conditions.
- Fix typos, clarify wording, and update outdated information.

## Important: edit source Markdown files only

Please make all content changes in the **Markdown source files** in this repository (for example: `Home.md`, `Towers.md`, `Sensorwiring.md`, `TERNOpenVPN.md`).

Do **not** edit generated HTML files in `docs/` (for example: `docs/*.html`)! Those files are automatically generated outputs and will be overwritten.

## Suggested workflows

a) send me an email with your ideas, text, files, etc at m.loew AT unimelb.edu.au
or 

b) Use github to send me a pull request:

1. Fork this repository.
2. Create a feature branch for your changes.
3. Edit the relevant `.md` files.
4. Commit with clear messages.
5. Open a pull request describing what you changed and why.

## What to include in pull requests

- A summary of the update.
- Links to standards, protocols, or references where relevant.
- Any references to papers or books etc should include either DOI or URL.

## Questions or ideas

If you are unsure where your contribution fits, please send me an email at m.loew AT unimelb.edu.au or open a github issue to discuss your idea before making larger changes.

Thanks for helping strengthen the guide for Australian flux tower development!
